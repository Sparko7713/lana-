# Lana - WeChat Mini Program

A modern WeChat Mini Program with beautiful login/registration interface featuring gradient backgrounds and glass-morphism design.

## 🌟 Features

- **Modern Login Interface**: Beautiful animated gradient background with semi-transparent form container
- **User Registration**: Complete registration flow with avatar upload and nickname validation
- **Responsive Design**: Optimized for mobile WeChat Mini Program environment
- **Session Management**: Persistent user authentication with local storage
- **Glass-morphism UI**: Modern design with backdrop blur effects and smooth animations

## 🚀 Getting Started

### Prerequisites
- WeChat Developer Tools
- WeChat Mini Program account

### Installation
1. Clone this repository
2. Open WeChat Developer Tools
3. Import the project folder
4. Configure your AppID in project settings
5. Preview or deploy to WeChat Mini Program platform

### Project Structure
```
├── app.js                    # Main application logic
├── app.json                  # App configuration and routing
├── app.wxss                  # Global styles
├── pages/
│   ├── login/               # Login/Registration page
│   └── home/                # Home page after authentication
└── images/                  # Static assets
```

## 🔧 Development

To customize the interface:
1. Modify styles in `pages/login/login.wxss` for UI changes
2. Update logic in `pages/login/login.js` for functionality changes
3. Edit layout in `pages/login/login.wxml` for structure changes
